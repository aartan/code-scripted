# CodeScripted

CodeScripted is a blog exploring the latest in software development and technology. It features articles on modern web development, programming concepts, and tools, with a clean, minimal interface designed to make technical content easy to discover and read.

Try online [demo](https://next-blog-nine-beta.vercel.app/)

## Features
- Article listings: Browse published articles with titles, descriptions, publication dates, and featured images.
- Search: Find posts using the homepage search field.
- Markdown content: Write articles in Markdown and manage their metadata using frontmatter.
- Responsive design: Read articles and browse posts across desktop and mobile devices.
- Minimal interface: Enjoy a clean layout focused on readability and content discovery.

## Technology

Built with Next.js and React, using TypeScript and Tailwind CSS for development and styling. Markdown content is processed with gray-matter, Remark, and remark-html, while date-fns handles date utilities and classnames simplifies conditional CSS class composition.
